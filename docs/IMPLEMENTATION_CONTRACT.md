# v0.1 implementation contract

Internal records and REST use snake_case. Time is integer milliseconds relative to asset start. Source data are versioned JSON; all indexes disposable. No reads/frames/model calls on `测试用视频` during development.

## Media/subtitles module (agent owned)

`media.probe(path: Path) -> dict` returns duration_ms, width, height, video_codec, audio_codec, format_name, streams. `fingerprint(path)->str` SHA256. `detect_shots(path,start_ms,end_ms)->list[dict]` returns id,start_ms,end_ms. `make_windows(shots,max_ms=6000)->list[dict]` id,shot_id,start_ms,end_ms. `extract_frame(path,at_ms,out_path,crop=None)->dict` id/path/at_ms (crop normalized x,y,width,height optional). `sample_times(start_ms,end_ms,count=4)->list[int]`. `create_proxy(path,out_path)->None` ffmpeg. `subtitles.parse_subtitles(path,duration_ms,offset_ms=0)->list[dict]` id,start_ms,end_ms,text,language,source,review_status. Validate required file/content and time bounds. `subtitles.merge_ocr_frames(frames,sample_interval_ms=500)->list[dict]`: frames [{frame_id,at_ms,lines:[{text,language,uncertain}],...}], empty frames break repeat runs; nonconsecutive repeated lines remain separate. `subtitles.candidate_frames(frames)->list[dict]` optional visual dedup retaining evidence/timing mapping. Source language best effort und where unknown, never translation.

## Providers/search module (agent owned)

`AIResult` dataclass data:any, usage:dict, request_count:int=1, cost:float|None=None.
`ProviderManager(settings_dir:Path)` persist sanitized profiles, keys via keyring/session/env. `list()->list[dict]`, `upsert(payload:dict)->dict`, `delete(id)`, `get(id)->dict`, `test(id,capability)->AIResult` async.
Profile fields id,name,base_url,model,capabilities:list (vision,subtitle,embedding,query,decision,answer), api_key optional input only, secret_mode session|keyring|env|none, env_var optional, timeout_s=90, max_concurrency=2, input_price_per_million/output_price_per_million optional. Empty key update preserves existing. No secrets in returned profiles/logs.
Async methods `analyze(id,frames,start_ms,end_ms)`, `recognize_subtitles(id,frames)`, `embed(id,texts)`, `interpret(id,query)`, `decide(id,query,candidates)`, `compose(id,query,candidates)` all -> AIResult. Frames dict id,path,at_ms. Vision returns summary,entities,events,spatial_observations,uncertainties,evidence_frame_ids; events start_ms,end_ms. Subtitle returns list [{frame_id,lines:[{text,language,uncertain}]}]. No fake/model fallback in production. Tests can inject HTTP MockTransport. JSON parse/schema bounded retry. API requests backend only.

`SearchEngine(index_dir:Path,providers:ProviderManager)`; async `rebuild(records:list[dict],embedding_profile_id:str|None=None)->dict`; sync `upsert(records:list[dict])->None` lexical. async `search(query:str,filters:dict|None=None,embedding_profile_id=None,query_profile_id=None,decision_profile_id=None,answer_profile_id=None,limit=10)->dict` -> results:list,degraded:list[str],explanation optional. sync `status()->dict`. Implement FTS5+Chinese normalize/exact substring+LanceDB embedding+RRF and evidence-preserving result IDs. Different embeddings independent namespaces, retain old successful index on rebuild failure.
Search record shape: id,asset_id,work_id,title,series,season,episode,version,kind=visual|subtitle,start_ms,end_ms,text,thumbnail (relative asset evidence path or null),evidence_frame_ids,record_id,source,review_status,entities/events optional,subtitle_text optional. Returned records add score,match_type=full|partial and match_reason. Can include adjacent-cue context records with explicit source IDs. Filters asset_id,work_id,kind,season,episode,character. Search must never invoke analyze/recognize.

## Core/library/jobs/API (root owned)

`Library(root:Path)` provides active record projection, immutable runs, file registration and annotations. Jobs queue in runtime/jobs.sqlite. HTTP API async providers/worker; SQLite connections per operation. App factory `create_app(data_dir:Path,start_worker=True,providers=None)`.

## Frontend API contract (frontend agent owned)

All API responses JSON; errors {detail:string|object}. Browser auth via `POST /api/session` body {token} setting HttpOnly cookie; token comes from startup URL `?token=...`, removed from history. 401 shows local token entry. Then `GET /api/bootstrap` -> {library_path,settings,provider_profiles,stats,tools:{ffmpeg,ffprobe},version}.
`GET /api/assets` -> list assets. Asset id,work_id,title,kind=movie|animation|series,series,season,episode,version,duration_ms,width,height,subtitle_mode=embedded|external,source_available,created_at,status,thumbnail_url optional. `POST /api/assets` body video_path,title,kind,series?,season?,episode?,version?,subtitle_mode,subtitle_path? (external mandatory),subtitle_offset_ms=0 -> asset. Register via pasted local absolute paths. `POST /api/assets/{id}/relocate` {video_path}.
`GET /api/assets/{id}` -> {asset,observations,subtitles,annotations,runs}. Observation id,window_id,shot_id,start_ms,end_ms,summary,entities,events,uncertainties,evidence_frame_ids,thumbnail_url,run_id. Subtitle id,start_ms,end_ms,text,language,source,review_status. `GET /api/assets/{id}/media` range stream. `GET /api/assets/{id}/frames/{frame_id}` image. `POST /api/assets/{id}/proxy` -> job.
`GET /api/profiles` list. `POST /api/profiles` profile fields above. `DELETE /api/profiles/{id}`. `POST /api/profiles/{id}/test` {capability} -> {ok,message,usage}.
`GET /api/settings`, `PUT /api/settings` body bindings:{vision?,subtitle?,embedding?,query?,decision?,answer?}, defaults:{window_ms:6000,frames_per_window:4,subtitle_fps:2,subtitle_crop:[0,.65,1,.35],max_requests:1000,max_cost:null} -> settings. Profile IDs can be null.
`POST /api/jobs/estimate` and `POST /api/jobs` body asset_id,stages:[vision|subtitle],start_ms=0,end_ms=null,window_ms=6000,frames_per_window=4,subtitle_fps=2,subtitle_crop:[0,.65,1,.35],max_requests=1000,max_cost=null,force=false. Profile bindings from settings snapshot. Estimate -> duration_ms,estimated_frames,estimated_requests,cost_estimate (nullable),warnings. Job -> id,type,status,progress,completed,total,asset_id,stage,message,error,usage,request_count,cost,created_at. `GET /api/jobs` list. `POST /api/jobs/{id}/{pause|resume|cancel|retry}` -> job. `GET /api/jobs/{id}` job. All monetary amounts currency declared USD only when rates configured; otherwise unknown.
`POST /api/search` {query,filters:{asset_id?,kind?,season?,episode?,character?},limit:10} -> {results,degraded,explanation?}. Results shape search record above plus thumbnail_url,media_url.
`POST /api/index/rebuild` {embeddings:bool=false} -> job. `GET /api/index/status` status.
`POST /api/assets/{id}/annotations` {record_id,summary?,note?,character_name?,entity_id?,aliases?:[],favorite?:bool} -> annotation. GET asset returns annotations. `GET /api/collections` -> saved result list. `GET /api/export/citations?format=markdown|json` download.
`POST /api/backups` {include_media:bool=false} -> {id,download_url}; `GET /api/backups/{id}` archive. `POST /api/restore` multipart file -> report (safe merge; existing conflicting files not overwritten). `GET /api/health` {status,version}. Jobs/index pending errors rendered. GUI Chinese default. Empty states no seeded synthetic films, results/mocks never portrayed as real recognition.
