所有模型替身仅注入测试进程。正常应用没有模拟识别后端或预置虚构电影记录。

## 已知边界

- 采样式画面理解与字幕识别可能漏掉极短事件；当前不做 ASR、独立字幕轨自动提取或自动跨镜头身份识别。
- 极低帧率视频中，如果单帧持续时间覆盖了整个后续分析窗口且其真实 PTS 在窗口之前，该窗口会报告失败，不编造窗口内时间戳；可扩大窗口后重试。
- 供应商中途断连或服务被强制终止时，无法确认远端计费。在途请求按最多三次保守计入请求预算，费用保持未知；核对供应商账单后调整预算继续。
- 新切分产生的新记录不会继承旧局部人物 ID 的身份映射；旧收藏仍保留并标为历史证据。

## 复现命令

```sh
uv sync --frozen --python 3.12 --extra dev
uv run pytest -q
uv run ruff check backend tests
cd frontend
npm ci
npm test
npm run typecheck
npm run build
```

测试使用临时目录和合成素材，不依赖现有测试影片或外部模型服务。Starlette 测试客户端目前会给出两条上游弃用提示，不影响测试结果。
