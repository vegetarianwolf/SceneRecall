# v0.1 验证记录

验证环境：2026-09-22，macOS / Apple Silicon，Python 3.12，Node.js 22。本次未使用真实 AI 凭据，未处理 `测试用视频/` 中的影片。

## 已验证

- 后端自动化：90 项通过，涵盖合成媒体、真实 PTS、可变帧率与末帧处理、SRT/VTT/ASS、双语 OCR 合并、模型协议与错误重试、混合检索、预算、任务恢复、纠错与身份版本、历史收藏、备份和恶意路径拒绝，以及同路径视频变化和恢复时内容指纹校验。
- 前端自动化：8 个组件工作流通过（Vitest / jsdom，不是实际浏览器端到端测试），涵盖强制外挂字幕、内嵌字幕模型绑定、密钥空值保留、阶段选择与估算失效、部分失败重试、预算恢复、证据结果定位与收藏、会话令牌处理。
- Python Ruff 检查、TypeScript 检查、Vite 生产构建通过。Python 和 npm 依赖分别由 `uv.lock`、`frontend/package-lock.json` 锁定。
- 在运行中的本机服务完成合成素材 HTTP 检查：生产 HTML/JS、会话认证、字幕文件导入、中文检索、HTTP 206 媒体范围请求、注释、收藏、引用导出及持久索引任务。
- 1 万条合成文字记录的临时检索基准：本地候选查询约 7 ms，索引构建约 3.5 秒；这是当前机器上的单次工程测量，不代表所有资料规模和所有问题的性能。

所有模型替身仅注入测试进程。正常应用没有模拟识别后端或预置虚构电影记录。

## 待验证

- 真实视觉模型、字幕模型和 embedding 接口的识别效果、调用延迟和计费；用户配置模型后先跑短片段，再按预算处理整片。
- 30 条有目标查询与 10 条无答案查询的人工评估；Top-5 命中率 80%、清晰字幕逐字准确率 95%、时间误差 1 秒都是验收目标，并未以真实影片证明。
- 浏览器可视化交互与响应式布局：自动浏览器工具对本地地址返回 `ERR_BLOCKED_BY_CLIENT`，因此未记为通过。生产构建、组件行为测试和实际 HTTP 集成检查已完成。
- Windows/Linux 和桌面安装包不属于本次平台验收。

## 已知边界

- 采样式画面理解与字幕识别可能漏掉极短事件；当前不做 ASR、独立字幕轨自动提取或自动跨镜头身份识别。
- 极低帧率视频中，如果单帧持续时间覆盖了整个后续分析窗口且其真实 PTS 在窗口之前，该窗口会报告失败，不编造窗口内时间戳；可扩大窗口后重试。
- 供应商中途断连或服务被强制终止时，无法确认远端计费。在途请求按最多三次保守计入请求预算，费用保持未知；核对供应商账单后调整预算继续。
- 新切分产生的新记录不会继承旧局部人物 ID 的身份映射；旧收藏仍保留并标为历史证据。

## 复现命令

```sh
uv sync --frozen --python 3.12 --extra dev
uv run pytest -q
uv run ruff check backend tests
cd frontend
npm ci
npm test
npm run typecheck
npm run build
```

测试使用临时目录和合成素材，不依赖现有测试影片或外部模型服务。Starlette 测试客户端目前会给出两条上游弃用提示，不影响测试结果。
